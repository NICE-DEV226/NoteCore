# NoteCore v0.5.0

**Votre base de notes devient un vrai outil de travail** : corbeille, note du
jour, recherche à opérateurs, import d'un dossier Markdown, historique de
versions, modèles, liens `[[note]]` et backlinks, rappels de révision,
mathématiques LaTeX, second volet, export vers un dossier surveillé et
vérification de mise à jour. Tout reste hors ligne : Internet n'est sollicité
que si vous le souhaitez, pour savoir qu'une version plus récente existe.

## Contenu

### Corbeille et fiabilité

- **Corbeille** : supprimer une note la met de côté (30 jours), avec
  restauration et suppression définitive. Plus rien ne disparaît d'un coup.
- **Rien n'est perdu non plus en sauvegarde** : les notes supprimées sont
  restaurées avec leur date de mise à la corbeille.
- Correctifs : extraits de recherche fiables, erreurs SQLite gérées par code,
  exports limités en mémoire avant chargement.

### Vague 1 — le quotidien

- **Note du jour** : bouton « Aujourd'hui » dans la barre latérale.
- **Opérateurs de recherche** : `tag:algo`, `dossier:réseaux` / `folder:`,
  `favori` — combinables avec le texte libre.
- **Cases à cocher cliquables** dans l'aperçu Markdown.

### Vague 2 — adoption et mémoire

- **Import d'un dossier Markdown** : chaque `.md` devient une note, les
  sous-dossiers deviennent des dossiers (migration Obsidian/Joplin, front
  matter `title:`/`tags:` reconnu).
- **Historique de versions** : chaque modification conserve un état
  (100 par note max), restauration en un clic — toujours réversible.
- **Modèles de notes** : cours, compte rendu, TP, idée de projet + vos propres
  modèles enregistrés.

### Vague 3 — révision et recherche

- **Rappel de révision** : invitation discrète quand des cartes sont dues.
- **Formules LaTeX** optionnelles ($…$, $$…$$) dans l'aperçu.
- **Recherche dans les pièces jointes** texte (CSV, TXT…) via un index FTS5.

### Vague 4 — relier les notes

- **Liens `[[note]]`** dans l'éditeur et l'aperçu, avec alias `[[note|texte]]`.
- **Backlinks** : dialogue « Liens » montrant les notes qui pointent vers la
  note ouverte et celles qu'elle cite.

### Vague 5 — système et packaging

- **Notifications OS** pour les révisions dues (réglage dédié).
- **Miroir Markdown** : export unidirectionnel vers un dossier surveillé
  (git, Obsidian…) — NoteCore reste la source de vérité, rien n'est réimporté.
- **Second volet** : deux notes côte à côte, le second en lecture seule.
- **macOS** : build universel (arm64 + x86_64) dans les releases.
- **Vérification de mise à jour** : une requête discrète au démarrage vers les
  releases GitHub, plus un bouton manuel dans Paramètres. Jamais bloquante,
  aucun téléchargement automatique — hors ligne, silence total.

## Téléchargements

| Fichier | Pour |
|---|---|
| `notecore-v0.5.0-windows-x64-setup.exe` | Windows 10 / 11, installateur (recommandé) |
| `notecore-v0.5.0-windows-x64.exe` | Windows 10 / 11, exécutable autonome |
| `notecore-v0.5.0-linux-amd64.deb` | Debian, Ubuntu et dérivés |
| `notecore-v0.5.0-linux-x64.tar.gz` | Toutes distributions (`./install.sh`) |
| `notecore-v0.5.0-macos-universal.zip` | macOS (Apple Silicon et Intel) |
| `SHA256SUMS` | Empreintes |

**Mettre à jour** : installez simplement la nouvelle version **par-dessus**
l'ancienne — pas besoin de désinstaller (`apt install ./nouveau.deb`, relancer
l'installateur Windows, relancer `./install.sh`, ou `makepkg -si` sous Arch).
Si le schéma de la base évolue, une copie de sécurité est faite avant migration.
Sous Arch : `git clone https://github.com/NICE-DEV226/NoteCore && cd NoteCore/packaging/aur && makepkg -si`.

## À savoir

- Les exécutables ne sont pas signés numériquement : Windows SmartScreen peut
  afficher « Windows a protégé votre ordinateur » (*Informations
  complémentaires* → *Exécuter quand même*, après vérification de l'empreinte).
- La vérification de mise à jour n'envoie que la version installée vers
  l'API publique GitHub — jamais le contenu de vos notes, et jamais sans que
  vous ayez une connexion. Vous pouvez l'ignorer sans risque.
