# NoteCore v0.7.0

La mise à jour devient interne : plus besoin de télécharger un
installateur à la main — un clic dans l'application suffit.

## Mise à jour dans l'application

- **Bouton « Mettre à jour »** dans la bannière de notification et dans
  Paramètres → Mise à jour : télécharge la release, vérifie l'empreinte
  SHA256 publiée, installe puis **redémarre l'application**.
- **Progression en direct** pendant le téléchargement.
- **Adapté à chaque installation** : `~/.local` (remplacement direct),
  `/usr/local`, pacman (`pkexec pacman -U`), Debian/Ubuntu
  (`pkexec apt-get`), Windows (installeur NSIS) et macOS (remplacement
  du `.app`).
- **Sécurité** : installation refusée sans empreinte SHA256 valide ;
  une seule invite d'authentification système quand les droits root
  sont requis (pacman/dpkg) ; mode inconnu → paquet déposé dans
  `~/Downloads`.
- **Hors ligne inchangé** : la vérification reste silencieuse et
  optionnelle, rien n'est téléchargé ni installé automatiquement.
