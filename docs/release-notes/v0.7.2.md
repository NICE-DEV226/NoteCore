# NoteCore v0.7.2

Correctifs de la navigation refondue en 0.7.1.

## Correctifs

- **Surlignage de navigation corrigé** : « Accueil » ne reste plus
  allumé en permanence. Un seul élément est maintenant fortement
  surligné à la fois — la destination réellement affichée (accueil,
  note ouverte, dossier) — tandis que le filtre de liste reste
  indiqué discrètement.
- **Échap ferme les menus** « Nouvelle note » et « Données ».
- **Accessibilité** : les filtres de la liste utilisent le pattern
  `aria-pressed` cohérent avec le reste de l'application.
- Icône manquante ajoutée (chevron du menu Données).
