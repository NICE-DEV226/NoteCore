# NoteCore v0.4.0

**Ranger ses notes sans effort** : dossiers imbriqués, glisser-déposer, une boîte
« À classer » qui propose un dossier pour chaque note, et des modèles de matière
pour créer *Cours / TD / TP / Révisions* en un clic.

## Contenu

### Dossiers imbriqués

Organisez comme vous pensez : *Semestre 3 › Réseaux › TD*. Deux matières peuvent
chacune avoir un dossier « TD ». Un dossier affiche aussi les notes de ses
sous-dossiers, avec son chemin en en-tête.

- **Glisser-déposer** : une note — ou plusieurs (`Ctrl/Maj+clic`) — sur un
  dossier ; un dossier sur un autre ; sur « Dossiers » pour revenir à la racine.
  Survoler un dossier replié l'ouvre.
- **Sans souris** : *Ranger dans…* (sur la sélection) et *Déplacer ce dossier…*
  ouvrent un sélecteur de destination, utilisable au clavier.
- **Rien n'est jamais perdu** : supprimer un dossier fait remonter ses notes et ses
  sous-dossiers d'un niveau. Un dossier ne peut pas être placé dans lui-même ni
  dans l'un de ses sous-dossiers. Un déplacement groupé réussit entièrement ou
  pas du tout.
- Ranger une note **ne change pas sa date de modification**.

### « À classer » : NoteCore propose, vous décidez

Les notes sans dossier arrivent dans **À classer** (barre latérale et accueil).
Pour chacune, NoteCore propose le dossier le plus probable, avec son niveau de
confiance (*très probable*, *probable*, *possible*) et **la raison** : étiquettes
et mots en commun avec les notes déjà rangées.

1. Cliquez **Ranger** pour accepter une proposition.
2. **Ranger les N sûres** range d'un coup les notes dont le dossier est évident.
   Les autres attendent votre décision.
3. La même proposition s'affiche dans l'éditeur d'une note sans dossier.

Le calcul est **local** (aucun modèle, aucun réseau) : il compare le vocabulaire
d'une note à celui des notes déjà rangées. Il est donc **peu fiable quand un
dossier est presque vide** ou que la note est très courte — dans ce cas,
NoteCore le dit plutôt que d'inventer. Rien n'est jamais rangé sans votre action.

### Modèles de matière

*Nouvelle matière* (bouton de la section *Dossiers*, palette `Ctrl/Cmd+K`, ou
*Ajouter une structure* sur un dossier) crée d'un coup :

| Modèle | Crée |
| --- | --- |
| Matière | Cours, TD, TP, Révisions, Examens |
| Matière simple | Cours, Exercices, Révisions |
| Projet | Cahier des charges, Conception, Développement, Documentation, Réunions |
| Semestre | Trois matières, chacune avec Cours et TD |
| Année | Semestre 1 et Semestre 2 |

Tapez le nom (« Réseaux »), vérifiez l'**aperçu**, validez. La structure est un
texte indenté (deux espaces = un niveau) que vous pouvez modifier avant de
créer ; **Enregistrer comme modèle…** garde vos propres structures (six au
plus). Création tout ou rien ; un dossier déjà présent au même endroit est
réutilisé, donc **réappliquer un modèle complète la structure sans rien
dupliquer**.

### Sécurité et fiabilité

- Une sauvegarde dont les dossiers formeraient une **boucle** ou seraient
  anormalement profonds est **refusée en bloc** à la restauration, sans toucher à
  vos données (protection contre une sauvegarde piégée ou corrompue).
- La sauvegarde, l'export Markdown et le partage `.notecore` conservent
  l'arborescence ; à l'import, « Semestre 3 / TD » reçu est fusionné avec le
  vôtre au lieu d'être dupliqué.

## Mise à niveau

Installer cette version **conserve vos notes**. Le schéma de la base passe en
**version 4** (dossiers imbriqués) : une copie de la base d'avant est écrite à
côté (`notecore.db.avant-migration-<date>`) avant la migration, et son chemin est
affiché au lancement. Vos dossiers actuels deviennent des dossiers à la racine.
Une version antérieure ne pourra plus restaurer une sauvegarde créée avec
celle-ci.

## Fichiers

Les empreintes SHA-256 de chaque fichier sont dans `SHA256SUMS`.

| Fichier | Pour |
| --- | --- |
| `notecore-v0.4.0-windows-x64-setup.exe` | Windows 10 / 11, installateur (recommandé) |
| `notecore-v0.4.0-windows-x64.exe` | Windows 10 / 11, exécutable autonome |
| `notecore-v0.4.0-linux-amd64.deb` | Debian, Ubuntu et dérivés |
| `notecore-v0.4.0-linux-x64.tar.gz` | Toutes distributions (`./install.sh`) |
| `SHA256SUMS` | Empreintes |

**Mettre à jour** : installez simplement la nouvelle version **par-dessus**
l'ancienne — pas besoin de désinstaller (`apt install ./nouveau.deb`, relancer
l'installateur Windows, relancer `./install.sh`, ou `makepkg -si` sous Arch).
Sous Arch : `git clone https://github.com/NICE-DEV226/NoteCore && cd NoteCore/packaging/aur && makepkg -si`.

## À savoir

- Les exécutables ne sont pas signés numériquement : Windows SmartScreen peut
  afficher « Windows a protégé votre ordinateur » (*Informations
  complémentaires* → *Exécuter quand même*, après vérification de l'empreinte).
- Le glisser-déposer a été vérifié dans un navigateur, pas encore sur toutes les
  configurations de l'application de bureau : si un glissement ne répond pas,
  *Ranger dans…* et *Déplacer ce dossier…* font la même chose. Signalez-le dans
  les *Issues*.
