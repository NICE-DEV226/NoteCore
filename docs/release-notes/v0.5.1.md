# NoteCore v0.5.1

Petite version correctrice : icône d'application lisible sur tous les fonds,
et premier test grandeur nature du vérificateur de mise à jour intégré.

## Contenu

- **Icône** : le glyphe de l'application n'est plus un tracé noir sur fond
  transparent (invisible sur une barre des tâches sombre) — il pose désormais
  en blanc sur une tuile de la couleur d'accent, comme dans l'interface.
- **Release Arch** : le paquet `.pkg.tar.zst` est de nouveau publié (le job
  avait échoué sur un problème de permissions, corrigé dans v0.5.0).

## Téléchargements

| Fichier | Pour |
|---|---|
| `notecore-v0.5.1-windows-x64-setup.exe` | Windows 10 / 11, installateur (recommandé) |
| `notecore-v0.5.1-windows-x64.exe` | Windows 10 / 11, exécutable autonome |
| `notecore-v0.5.1-linux-amd64.deb` | Debian, Ubuntu et dérivés |
| `notecore-v0.5.1-linux-x64.tar.gz` | Toutes distributions (`./install.sh`) |
| `notecore-v0.5.1-macos-universal.zip` | macOS (Apple Silicon et Intel) |
| `notecore-0.5.1-1-x86_64.pkg.tar.zst` | Arch Linux (`sudo pacman -U …`) |
| `SHA256SUMS` | Empreintes |

**Mettre à jour** : comme d'habitude, par-dessus l'ancienne version — vos
notes et réglages sont conservés. Sur Arch : `sudo pacman -U
notecore-0.5.1-1-x86_64.pkg.tar.zst`.

## À savoir

- Si vous êtes en v0.5.0 avec Internet, la bannière « NoteCore 0.5.1 est
  disponible » devrait apparaître au prochain lancement — c'est la première
  fois que le vérificateur de mise à jour est testé en conditions réelles.
