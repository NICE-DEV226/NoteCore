# NoteCore v0.3.0

Lire ses fichiers joints dans NoteCore, **partager des notes sans Internet** et
**importer** celles des autres.

## Contenu

### Lire et parcourir ses fichiers joints

- Un clic sur un fichier joint (ou sur une image d'une note) ouvre une
  **visionneuse** : images (zoom), **PDF**, Markdown, texte et code, tableaux
  CSV, contenu d'une archive `.zip`, audio et vidéo. `←` `→` changent de
  fichier, `+` `-` zooment, `Échap` ferme.
- Nouvelle vue **Fichiers** (barre latérale) : tous les fichiers de toutes vos
  notes, filtre par type et par nom, vignettes d'images, retour à la note.
- *Ouvrir* les confie à l'application de votre système, mais **seulement les
  types passifs** (documents, images, son, vidéo, archives) : un fichier
  exécutable n'est jamais lancé par NoteCore.

### Partager des notes sans connexion

Bouton **Partager** dans l'éditeur (ou `Ctrl/Cmd+K` → « Partager… »).

1. Choisissez ce qui part : une note, un dossier, ou tout.
2. Choisissez le format : **paquet NoteCore** (dossiers, étiquettes et fichiers
   joints ; réimportable à l'identique) ou **Markdown (.zip)** (lisible partout).
3. Facultatif : un **mot de passe** (AES-256), conseillé sur un Wi-Fi partagé.
4. Transmettez :
   - **Enregistrer un fichier** → clé USB, Bluetooth, dossier partagé…
   - **Envoyer sur le réseau local** → un **lien** et un **QR code**. L'autre
     appareil (un téléphone suffit, sans NoteCore) scanne le code ; avec
     NoteCore : *Importer → Depuis un autre appareil*, puis collez l'adresse.
     **Le lien ne sert qu'une fois et expire au bout de 10 minutes.**

Les deux appareils doivent être sur le **même réseau** (Wi-Fi de la salle, ou
point d'accès d'un téléphone). **Internet n'est pas nécessaire.** Sous Windows,
le pare-feu demande l'autorisation la première fois : choisissez *Réseaux
privés*.

### Importer

*Paramètres → Données → Importer des notes*, ou `Ctrl/Cmd+K` → « Importer… » :
paquets `.notecore`, archives d'export `.zip` et fichiers Markdown d'autres
outils (titre et étiquettes de l'en-tête reconnus).

**Importer n'écrase jamais rien.** Une note identique à l'une des vôtres est
ignorée — réimporter le même paquet n'ajoute donc rien — et une note de même
titre mais différente est ajoutée à côté, avec « (importée) » dans son titre.
Un rapport indique ce qui a été importé, ignoré ou ajouté.

### Sécurité

- Le réseau local n'est pas chiffré : sur un Wi-Fi partagé avec des inconnus,
  **mettez un mot de passe** au paquet.
- NoteCore ne se connecte **jamais à Internet** : la réception n'accepte que
  des adresses de votre réseau local.
- Le serveur d'envoi ne sert qu'un fichier, derrière un jeton aléatoire, pour
  un seul téléchargement, puis s'arrête et vide la mémoire.

### Autres changements

- Merriweather retirée du catalogue de polices (22 polices) : une seule police
  pesait 370 Ko.

## Mise à niveau

Installer cette version **conserve vos notes**. Aucune migration de schéma
(la base reste en version 3). Le pare-feu de Windows peut demander une
autorisation la première fois que vous partagez sur le réseau local.

## Fichiers

Les empreintes SHA-256 de chaque fichier sont dans `SHA256SUMS`.

| Fichier | Pour |
| --- | --- |
| `notecore-v0.3.0-windows-x64-setup.exe` | Windows 10 / 11, installateur (recommandé) |
| `notecore-v0.3.0-windows-x64.exe` | Windows 10 / 11, exécutable autonome |
| `notecore-v0.3.0-linux-amd64.deb` | Debian, Ubuntu et dérivés |
| `notecore-v0.3.0-linux-x64.tar.gz` | Toutes distributions (`./install.sh`) |
| `SHA256SUMS` | Empreintes |

Sous Arch : `git clone https://github.com/NICE-DEV226/NoteCore && cd NoteCore/packaging/aur && makepkg -si`.

## À savoir

- Les exécutables ne sont pas signés numériquement : Windows SmartScreen peut
  afficher « Windows a protégé votre ordinateur » (*Informations
  complémentaires* → *Exécuter quand même*, après vérification de l'empreinte).
- Premier retour attendu : l'ouverture d'un fichier avec l'application du
  système, la lecture des PDF et l'envoi entre deux appareils ont été testés
  par des tests automatiques et dans un navigateur, mais pas encore sur
  toutes les configurations. Signalez tout comportement inattendu sur la page
  des *Issues*.
