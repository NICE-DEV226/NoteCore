# NoteCore v0.6.0

La version « idées » : un mode **Brainstorm** pour structurer une note en
plan arborescent, et une vue **Carte** qui la rend en mind map — le tout
toujours stocké en simple Markdown, sans rien changer à vos données.

## Nouveautés

- **Mode Brainstorm** : l'éditeur devient un outline (style Workflowy).
  Entrée = nouvelle puce, `Tab`/`Maj+Tab` = indenter/désindenter,
  flèches = naviguer, `Alt+↑/↓` = déplacer une branche,
  `Backspace`/`Delete` = fusionner les puces, cases `[ ]`/`[x]` cliquables,
  branches repliables.
- **Zoom sur une branche** : `Ctrl+Maj+→` isole une sous-arborescence,
  fil d'Ariane pour remonter, `Échap` dézoome d'un niveau.
- **Vue Carte** : le même outline rendu en mind map SVG — glisser pour
  déplacer, molette pour zoomer, ajustement automatique. Lecture seule :
  on structure en Brainstorm, on admire en Carte.
- **Panneaux repliables** : la barre latérale et la liste des notes se
  réduisent en rail d'icônes (`Ctrl+B` pour la barre latérale), état
  mémorisé — fini les trois colonnes permanentes sur petit écran.
- **Split-screen annulable** : `Échap` referme le volet secondaire,
  en plus du bouton × et du basculeur.

## Contenu technique

- L'outline et la carte partagent le même format : listes Markdown
  indentées. Recherche FTS, historique de versions, sauvegarde,
  export et miroir Markdown fonctionnent sans adaptation.
- Icône du lanceur corrigée : glyphe clair sur tuile accent, visible
  sur les thèmes sombres.
