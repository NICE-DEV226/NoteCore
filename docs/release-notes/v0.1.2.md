# NoteCore v0.1.2

Mise à niveau sans perte de données, et corrections de finition.

## Contenu

### Conserver ses données à l'installation d'une version plus récente

Installer une version plus récente ne touche pas à vos notes : la base vit
hors du dossier d'installation, remplacer le binaire ne change rien.

En revanche, une nouvelle version peut devoir migrer le schéma de la base
pour l'adapter à ses ajouts. Cette migration s'applique désormais en deux
temps :

1. **Copie de sécurité** — avant la moindre écriture, la base telle qu'elle
   est chez l'utilisateur est copiée à côté d'elle-même
   (`notecore.db.avant-migration-<date>`, permissions `0600`).
2. **Migration** — les migrations sont appliquées, chacune dans sa propre
   transaction.

Le chemin de la copie conservée est affiché au lancement et consigné dans
le journal. Un fichier n'est jamais laissé sur le disque sans le dire, et
un échec de migration reste rattrapable : la base d'avant est intacte.

Une installation neuve n'écrit aucune copie — rien à conserver — et une
base déjà à jour n'en écrit pas non plus : la copie n'apparaît qu'au
moment exact où le schéma change.

```

```
