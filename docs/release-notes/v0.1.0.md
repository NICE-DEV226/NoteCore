# NoteCore v0.1.0

## Fonctionnalités

- Prise de notes Markdown locale et hors ligne.
- Notes, dossiers, tags, épinglage.
- Recherche plein texte (SQLite FTS5) avec surlignage des extraits.
- Éditeur et aperçu, barres de mise en forme (titres, gras, italique, evidence, code, listes, cases, citations, liens, images, séparateur, nettoyage).
- Raccourcis `Ctrl/Cmd+B` et `Ctrl/Cmd+I`, indentation multi-lignes avec `Tab`/`Shift+Tab`.
- Pièces jointes locales (images + fichiers, 10 Mio max), mimetypes déduits côté backend, aperçu inline des images.
- Export d'une note (.md + dossier d'assets) et export de l'ensemble (archive .zip + manifeste).
- Sauvegarde complète vérifiable (empreinte SHA-256), restauration avec confirmation et copie de sécurité automatique.
- Thème clair/sombre (suivant le système), préférences d'affichage (police, taille, largeur).
- Enregistrement automatique (800ms), état de sauvegarde (sauvegardé/modifié/en cours/erreur), `Ctrl/Cmd+S`.

## Architecture

- Monolithe modulaire Go + Wails v2 + Svelte 5 + TypeScript.
- SQLite + WAL, migrations, FTS5, recherche portable.
- Pas de compte, pas de serveur, pas de synchronisation.

## Build

- Linux (Ubuntu/Debian, Arch) et Windows 10/11 via build croisé.
- CI (Ubuntu 24.04) : frontend + backend + tests + build Linux. Workflow Windows sur demande.
